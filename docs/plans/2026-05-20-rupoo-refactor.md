在 `exec_think()` 方法前添加一个辅助函数:

```rust
/// Build the system prompt from external config file, falling back to default.
fn build_system_prompt() -> String {
    let paths = [
        dirs::home_dir()
            .map(|p| p.join(".rupoo").join("prompt.toml")),
        Some(std::path::PathBuf::from("prompt.default.toml")),
    ];

    for path in paths.into_iter().flatten() {
        if path.exists() {
            if let Ok(content) = std::fs::read_to_string(&path) {
                if let Ok(config) = content.parse::<toml::Value>() {
                    if let Some(template) = config.get("system_prompt")
                        .and_then(|v| v.get("template"))
                        .and_then(|v| v.as_str())
                    {
                        return template.to_string();
                    }
                }
            }
        }
    }

    // Fallback: hardcoded default (same content as prompt.default.toml)
    "\
    You are Rupoo, an AI-powered terminal assistant running inside the user's terminal.\
    ...\
    ".to_string()
}
```

然后 `exec_think()` 中 317 行替换:

```rust
// Before:

".to_string();

// After:
let mut system = Self::build_system_prompt();
```
